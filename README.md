# Vien Finder

Android real-time camera vein contrast enhancement prototype for Samsung Galaxy A56.

Built with the Android Camera2 API; offline processing, no account or internet connection.

**The enhanced image is not a validated map of vein location or depth and must not guide needle placement on its own.**

Download the Android APK from [Releases](https://github.com/MohamedTaltlo/Vien-Finder/releases) after the GitHub Actions build finishes.
